# Cheats

Type the word while you are playing (no need to open anything), or dial the
number on the phone's keypad. Vehicles appear in front of you and you are put in
the driving seat.

| Word | Number | What it does |
|---|---|---|
| ROADSTER | 5550101 | sports car |
| SUPERCAR | 5550102 | supercar |
| SPORTBIKE | 5550103 | sport motorbike |
| HADSON | 5550104 | Hadson cruiser |
| TOURING | 5550105 | Hadson tourer |
| KEICAR | 5550106 | kei car |
| TAXICAB | 5550107 | taxi |
| BIGBUS | 5550108 | bus |
| TRUCKER | 5550109 | box truck |
| PATROL | 5550110 | police car |
| AMBULANCE | 5550111 | ambulance |
| FIRETRUCK | 5550112 | fire engine |
| RYDECAR | 5550113 | Ryde saloon |
| SCOOTER | 5550114 | delivery scooter |
| DIRTBIKE | 5550115 | dirt bike |
| TRAILBIKE | 5550116 | mountain bike |
| AIRPLANE | 5550120 | aircraft (when added) |
| HELICOPTER | 5550121 | helicopter (when added) |
| MONEYBAGS | 5550130 | +¥1,000,000 |
| HEALTHY | 5550131 | full health, calm nerves |
| MIDDAY / MIDNIGHT / SUNRISE / SUNSET | 5550132-5550135 | set the time |
| LIGHTSOUT | 5550136 | your headlights on |

From the browser console, `cheat("roadster")` does the same.

To add an aircraft later, give it a vehicle kind (`name: "plane"`) and its code
starts working; until then those codes say there are none yet.
