# Salary Man case cover

The current cover is the **DHInc / cinematic anime SOTI edition**:

- `Salary-Man-DHInc-cinematic-anime-A4-print.pdf`: A4 landscape print sheet, 273 × 171 mm insert. Print at 100% / Actual size, with Fit to page disabled.
- `Salary-Man-DHInc-cinematic-anime-cover.png`: full-wrap illustrated cover.

This edition uses cinematic anime illustration based on the actual SOTI tower, street composition and Seiko reference renders from the game. Lighting, reflections and painted detail are artistic interpretations; it is promotional artwork rather than a gameplay screenshot. It retains DHInc branding and the station-sign identity.

The earlier **DHInc / actual-render SOTI street edition** remains available:

- `Salary-Man-DHInc-A4-print.pdf`: A4 landscape sheet, crop marks, 273 × 171 mm insert with a 13 mm spine. Print at 100% / Actual size and disable Fit to page; check your physical case dimensions.
- `Salary-Man-DHInc-cover.pdf`: trim-size vector master.
- `Salary-Man-DHInc-cover.png`: full-wrap preview.
- `DHInc-logo.svg`: studio monogram and wordmark, ivory on transparent.
- `Salary-Man-station-logo.svg`: station-sign title identity.

Seiko's silhouette uses the game's office character mesh, with a posed head and black material. SOTI, neighbouring buildings, ground, cloud sky and facade textures are rendered directly from the staged 0.6.4 game at SOTI's generated world coordinates (seed 19640101). Architecture is not generated or repainted. The back uses a second actual in-engine view. The new typography, station sign and DHInc identity are vector artwork. Developer branding on this cover is DHInc; this artwork change does not alter the game's runtime credits.

Earlier covers remain in this folder as alternatives. This is a custom collector sleeve for the PC game, not an Xbox port. The repository is private: sign into the GitHub account with repository access before opening file pages, then use Download raw file. Unauthenticated raw URLs can return 404.
